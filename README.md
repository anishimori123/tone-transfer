# Tone Transfer Studio

Split-screen tool: type on left, get pure tone transfer on right — no extra hype sentences.

## Features
- 🎧 Left: Type original
- ➡️ Right: Same sentence, different voice (dropdown where it says "Famous DJ • Verified")
- Pure Transfer Rule: output sentence count = input sentence count, word count ±30%
- Auto-fix spelling & grammar
- Professional vocab upgrade (good→compelling, thing→initiative, etc.)
- CEO Interview Suite: Jamie Dimon, Jensen Huang, Mark Zuckerberg
- Sports Energy: Football Coach Post-Game, Noah Lyles
- DJ & Artists: Famous DJ, Lo-Fi, Snoop, Yoda, Pirate, Drake, Travis
- 🎙️ Interview Ready Mode
- 📺 YouTube Study Mode (paste transcript)

## Usage
Open index.html in browser. No build needed.
